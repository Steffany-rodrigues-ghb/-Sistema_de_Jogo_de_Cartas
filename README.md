# -Sistema_de_Jogo_de_Cartas
Este repositório contém a resolução de uma atividade prática focada nos fundamentos da linguagem JavaScript. O projeto simula a lógica de um jogo de cartas e criaturas, exercitando o uso de estruturas de dados e controle de fluxo. 
O que foi praticado
Neste exercício, foquei em aplicar os seguintes pontos:

Como criar e usar variáveis e listas (arrays).

O uso de laços de repetição (for...of) para ler dados em sequência.

A criação de funções que recebem informações e retornam um resultado.

O uso de estruturas de decisão (if e else) para criar a lógica do jogo.

O que o código faz
Avaliação de Cartas: Uma função que olha o poder da carta e diz se ela é "Forte" ou "Fraca" baseada em um valor de corte.

Análise de Baralho: Um loop que percorre uma lista de cartas e mostra no console a classificação de cada uma delas.

Contador de Criaturas: Uma função que busca por um nome específico dentro de uma lista de invocações e conta quantas vezes ele aparece.
